# chromprocessor

Python tools for chromatogram parsing, preprocessing, peak detection, tracking, and deconvolution.

## Install

```powershell
python -m pip install -e .
```

## Quick import check

```powershell
python -c "import chromprocessor; print(chromprocessor.__name__)"
```
